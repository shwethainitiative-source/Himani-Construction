# Supabase Database and Storage Setup Guide

To connect the Himani Construction & Interiors portal with Supabase, run the following SQL script inside the **SQL Editor** of your Supabase Dashboard, and configure the storage bucket as described below.

---

## 1. Database Table Schema Setup

Copy and run this SQL script in the **Supabase SQL Editor** to create the tables, configure indexes, enable Row Level Security (RLS), and set up security policies.

```sql
-- =======================================================
-- 1. CREATE PROJECTS TABLE
-- =======================================================
CREATE TABLE IF NOT EXISTS public.projects (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT now() NOT NULL,
    title text NOT NULL,
    category text NOT NULL, -- residential, commercial, interior, renovation
    description text NOT NULL,
    date date DEFAULT CURRENT_DATE NOT NULL,
    img text NOT NULL
);

-- Enable RLS
ALTER TABLE public.projects ENABLE ROW LEVEL SECURITY;

-- Drop existing policies if any
DROP POLICY IF EXISTS "Allow public read access for projects" ON public.projects;
DROP POLICY IF EXISTS "Allow authenticated admin write access for projects" ON public.projects;

-- Create Policies
CREATE POLICY "Allow public read access for projects" 
ON public.projects FOR SELECT 
USING (true);

CREATE POLICY "Allow authenticated admin write access for projects" 
ON public.projects FOR ALL 
TO authenticated 
USING (true) 
WITH CHECK (true);


-- =======================================================
-- 2. CREATE BLOGS TABLE
-- =======================================================
CREATE TABLE IF NOT EXISTS public.blogs (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT now() NOT NULL,
    title text NOT NULL,
    category text NOT NULL, -- e.g. Architecture, Interior Design
    description text NOT NULL,
    date date DEFAULT CURRENT_DATE NOT NULL,
    img text NOT NULL,
    featured boolean DEFAULT false NOT NULL
);

-- Enable RLS
ALTER TABLE public.blogs ENABLE ROW LEVEL SECURITY;

-- Drop existing policies if any
DROP POLICY IF EXISTS "Allow public read access for blogs" ON public.blogs;
DROP POLICY IF EXISTS "Allow authenticated admin write access for blogs" ON public.blogs;

-- Create Policies
CREATE POLICY "Allow public read access for blogs" 
ON public.blogs FOR SELECT 
USING (true);

CREATE POLICY "Allow authenticated admin write access for blogs" 
ON public.blogs FOR ALL 
TO authenticated 
USING (true) 
WITH CHECK (true);
```

## 2. Supabase Storage Bucket Setup

To store uploaded project and blog images, we need to create a **Storage Bucket**:

1. Go to the **Storage** section in your Supabase Dashboard.
2. Click **New Bucket**.
3. Name the bucket exactly: `himani-construction`.
4. Toggle **Public Bucket** to **ON** (this allows public access to fetch image URLs).
5. Click **Create Bucket**.

### Storage Security Policies
Inside the `himani-construction` bucket configuration, under **Policies**:
1. Add a policy under **Allowed Actions**:
   - Name: `Allow public select access`
   - Allowed operations: `SELECT` (Read)
   - Roles: `public`
2. Add another policy for administrators:
   - Name: `Allow authenticated upload/edit/delete`
   - Allowed operations: `INSERT`, `UPDATE`, `DELETE`, `SELECT`
   - Target Roles: `authenticated`
